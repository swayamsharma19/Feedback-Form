# 📝 Feedback Form 

A simple and clean feedback form web application built using Spring Boot.
Users can enter their name and message through a web interface, and the data is handled by the backend.

---

## 🚀 Features

* Submit feedback (Name + Message)
* Simple and clean UI
* Backend using Spring Boot
* MVC architecture (Controller, Model, Repository)
* Uses Thymeleaf for templates

---

## 🛠️ Tech Stack

* Java (Spring Boot)
* HTML, CSS
* Thymeleaf
* Maven
* IntelliJ IDEA

## ⚙️ How to Run

1. Open the project in IntelliJ IDEA

2. Run the main file:

```
FeedbackApplication.java
```

3. Open browser and go to:

```
http://localhost:8080
```
